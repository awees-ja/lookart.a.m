# صفحة هبوط احترافية لمصمم جرافيك

صفحة هبوط عصرية واحترافية مصممة بعناية لمصمم جرافيك متخصص في الشعارات والهويات البصرية.

## 🎨 المميزات الرئيسية

### التصميم والواجهة
- **تصميم عصري وفخم**: خلفية داكنة مع لمسات بنفسجية جميلة
- **دعم كامل للعربية**: واجهة RTL متكاملة
- **متجاوب تماماً**: يعمل بسلاسة على جميع أحجام الشاشات
- **حركات تفاعلية ناعمة**: تأثيرات بصرية احترافية وسلسة

### الأقسام المتضمنة
1. **الصفحة الرئيسية (Hero)**: عرض قوي برسالة واضحة وأزرار تحويل
2. **معرض الأعمال**: عرض أبرز المشاريع والأعمال السابقة
3. **الخدمات المقدمة**: 6 خدمات رئيسية مع رموز توضيحية
4. **المميزات**: لماذا تختارني - 6 نقاط قوة
5. **مراحل التنفيذ**: شرح واضح لعملية العمل من البداية للنهاية
6. **آراء العملاء**: تقييمات من عملاء راضين
7. **التواصل**: نموذج اتصال + معلومات التواصل المباشر (واتساب، بريد، هاتف)
8. **التذييل**: روابط مهمة ومعلومات إضافية

### التقنيات المستخدمة
- **HTML5**: معايير دولية حديثة
- **CSS3**: تصميم متقدم مع حركات وتأثيرات
- **JavaScript Vanilla**: بدون مكتبات خارجية، أداء سريع
- **Responsive Design**: تصميم سائل يتكيف مع جميع الأجهزة

### ميزات الأداء والتحسينات
- تحميل سريع جداً
- محسّن لمحركات البحث (SEO)
- سهل التخصيص والتعديل
- نسبة تحويل عالية (CTA واضحة)

## 🚀 طريقة الاستخدام

### الفتح المباشر
1. افتح ملف `index.html` في متصفح الويب الخاص بك
2. الصفحة جاهزة للعمل فوراً!

### التشغيل على خادم محلي
```bash
# استخدام Python 3
python -m http.server 8000

# أو استخدام Node.js (http-server)
npx http-server
```

ثم افتح `http://localhost:8000` في متصفحك

## ✏️ تعديل المحتوى

### تعديل المعلومات الأساسية
في ملف `index.html`:

```html
<!-- اسم المصمم/الشركة -->
<span class="logo-text">تصميم احترافي</span>

<!-- الرسالة الرئيسية -->
<h1 class="hero-title">تصميم جرافيك <span class="highlight">احترافي</span> وفريد</h1>

<!-- رابط واتساب (استبدل برقمك) -->
<a href="https://wa.me/201234567890?text=مرحباً، أود الاستفسار عن خدماتك">
```

### تعديل الألوان
في ملف `css/style.css`، عدّل متغيرات CSS في الأعلى:

```css
:root {
    --primary-color: #9D4EDD;      /* اللون الأساسي البنفسجي */
    --secondary-color: #C77DFF;    /* اللون الثانوي */
    --accent-color: #5A189A;       /* اللون الداكن */
    --dark-bg: #0A0014;            /* الخلفية الداكنة */
    /* ... الألوان الأخرى ... */
}
```

### إضافة صور
ضع الصور في مجلد `assets/images/` واستبدل الرموز التعبيرية بـ:

```html
<img src="assets/images/your-image.jpg" alt="وصف الصورة">
```

### تعديل رقم الواتساب
ابحث عن `wa.me/201234567890` واستبدله برقمك الخاص بصيغة:
```
https://wa.me/[رمز الدولة][الرقم]
```

مثال: `https://wa.me/966505555555` (السعودية)

### تعديل البريد الإلكتروني والهاتف
```html
<a href="mailto:your-email@example.com">
<a href="tel:+201234567890">
```

## 📧 إعداد نموذج الاتصال (اختياري)

حالياً، النموذج يعرض رسالة تأكيد. لتفعيل الإرسال:

**خيار 1: استخدام Formspree**
```javascript
// في ملف js/main.js، استبدل جزء الإرسال بـ:
fetch('https://formspree.io/f/YOUR_ID', {
    method: 'POST',
    body: new FormData(contactForm),
    headers: { 'Accept': 'application/json' }
})
```

**خيار 2: استخدام خدمة أخرى**
- EmailJS
- Basin
- Getform
